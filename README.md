# Erick Amorim — Logística & Dados

Portfólio pessoal (currículo online): logística, operações e análise de dados.

Site: https://erickkamorim.github.io

## Estrutura

Site de página única com navegação por âncoras. Menu fixo com as 4 seções:

- **Sobre mim** (`#sobre`): apresentação, informações pessoais, hobbies e trajetória
- **Formação** (`#formacao`): graduações, idiomas, cursos e ferramentas
- **Portfólio** (`#portfolio`): links para os projetos publicados
- **Contato** (`#contato`): formulário com validação em JavaScript e envio simulado

## Arquivos

```
index.html        estrutura da página (HTML5)
css/style.css     estilos (CSS3 puro, sem frameworks), incluindo o tema claro
js/script.js      JavaScript puro: tema claro/escuro, menu ativo, galeria e formulário
assets/           imagens do site
```

Tecnologias: HTML5, CSS3 e JavaScript, sem frameworks ou bibliotecas. Publicado no GitHub Pages.
